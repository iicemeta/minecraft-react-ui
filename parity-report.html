为什么不照抄 upstream 的 .npmrc
upstream 在仓库根提交了 //registry.npmjs.org/:_authToken=${NPM_TOKEN}。 项目级 .npmrc 优先级高于用户级 ~/.npmrc，所以当 NPM_TOKEN 未设置时， 它会注入一个空 token，静默顶掉 npm login 刚写进 ~/.npmrc 的凭据。症状：
$ npm login # 成功 $ npm whoami npm error code E401
用 npm config list 可确认：
; //registry.npmjs.org/:_authToken = (protected) ; overridden by project
正确做法：本地靠 npm login 写 ~/.npmrc；CI 靠 actions/setup-node 的 registry-url 自行生成 runner 内 .npmrc 并读取 NODE_AUTH_TOKEN。 仓库两边都不需要 .npmrc，已从仓库删除；.npmrc 保留在 .gitignore 中防止误提交。
