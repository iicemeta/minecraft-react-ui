# MenuIcon

**Group:** Content · `import { MenuIcon } from "@iicemeta/minecraft-react-ui"`

The vertical-ellipsis glyph used by DropdownMenu. It draws the icon only — wrap it in a Button yourself if you need a click target.

## Props

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `className` | `string` | — | Appended to the MenuIcon class list. |

## Examples

### 1. Default and recoloured

className is the only styling hook.

```tsx
<MenuIcon />
<MenuIcon className="site-icon-tinted" />
```
